# Bro

Restate your previous response like one human talking to another.

- Preserve the answer, decisions, facts, and material caveats.
- Use plain words and short sentences. Explain any jargon that must remain.
- Include the context a cold reader needs. Do not assume the user has read the files or sources you read.
- Cut repetition, throat-clearing, and implementation detail that does not help the user understand the answer.
- If the invocation includes a specific focus, give that part extra attention.
- Return only the restatement. Do not discuss this skill or the rewriting process.

The result is complete when the user can understand the response without the agent's hidden context.
