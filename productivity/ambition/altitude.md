# Altitude

A task is the user's best guess at how to reach an outcome. Altitude asks for the outcome. The request moves from "fix this crash" to "keep the app crash-free".

Altitude fits when a real end result sits behind the request. A good sign is that people would hold meetings about the work. For creative work, where the making is the point, say that Altitude does not fit and use another type.

## Questions

1. What happens next with this deliverable? Name the outcome it serves: the goal beyond the goal.
2. Which repeating work is this request one instance of, and what would it mean for that outcome to hold without a new request each time?
3. What access, data, and environments would an agent need to own that outcome? Sort them into what exists here and what is missing.
4. What, other than the user or the agent, would show the outcome holds: over time, and against this project's own history?

## Moves for the rewrite

- **Climb one rung at a time.** The rungs are: explain (what changed, why, and what to do about it), decide (the few most urgent decisions, each with arguments for and against), and redesign (a better way to reach the outcome than the current deliverable). Write the rewrite at the highest rung that the reachable material supports and that question 4 can check. An outcome with no check, such as "make money", is one rung too high.
- **Give all the material.** Ask for the work to start from everything reachable about the situation, in place of the numbers or template the plain request would update.
- **Prerequisites first.** List the missing access, data, and environments from question 3 at the top of the rewrite as things to set up; a missing decision goes with the open choices. An agent owns an outcome only when it can observe it and verify its own fixes, so the setup comes first. For "keep the app crash-free", the setup was crash reports it can fetch, a map from app version to commit, and machines on each platform to reproduce on.
- **Prove it on history.** Ask for evidence that the new approach would have caught past problems sooner, and for a period where it runs beside the current one.
- **Standing work.** When the outcome needs recurring attention, describe the recurring check in the rewrite as a proposal. The user decides whether to schedule it.
